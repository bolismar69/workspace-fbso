# Orchestration

Este diretório concentra **definições versionadas** de orquestração (workflows, scripts e padrões), separando claramente:

- **Definição e versionamento** (aqui em `orchestration/`)
- **Deploy/runtime** das plataformas de orquestração (em `devops/`)

Atualmente o padrão adotado para workflows é **Kestra** (ver `orchestration/kestra/`).
