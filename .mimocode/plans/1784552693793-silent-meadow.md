### 2. Estrutura de Pacotes

- Referência ao ARCHITECTURE.md §2 para detalhes

### 3. Padrões de Código
- **Entity**: extende `BaseEntity`, usa `@Column` com RowMapper
- **Repository**: extende `BaseRepository<T>`, usa `hasTenantColumn` flag
- **Service**: `@Service` + `@Transactional`, anotações `@Auditable` em mutations
- **Controller**: `@RestController` + `@RequiresPermission(resource, action)`
- **DTO**: records Java, `@Valid` + Bean Validation nos requests
- **Exception**: extende `BusinessException`, handler no `GlobalExceptionHandler`

### 4. Pipeline de Segurança (por Request)
- JwtAuthenticationFilter → TenantContext → RbacAspect → TenantAwareDataSource (RLS) → BaseRepository → AuditAspect
- Referência ao ARCHITECTURE.md §4

### 5. Padão de Erros RFC 7807
```json
{
  "type": "https://api.fbso.org/errors/<error-code>",
  "title": "<mensagem>",
  "status": <http-status>,
  "detail": "<detalhe opcional>"
}
```
- Beans Validation: `ErrorResponse.validation()` com `FieldError[]`
- 403 sempre: `{"title": "Acesso negado", "status": 403, "detail": "Você não tem permissão..."}`
