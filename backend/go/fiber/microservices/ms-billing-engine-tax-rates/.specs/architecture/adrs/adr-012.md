# ADR-012: CCT como Metadado de Auditoria (não Chave Primária)

**Status:** ✅ Aceito

**Substitui:** Nenhum

## Contexto

A tabela oficial da RFB tem 2 níveis hierárquicos:
- **CST** (3 dígitos, 18 valores): Código da Situação Tributária — vai no documento fiscal (NF-e, NFC-e, CT-e)
- **CCT** (6 dígitos, 164 valores): Código da Classificação Tributária — subclassificação detalhada que referencia artigos específicos da LC 214/2025

Exemplo: CST `000` (Tributação integral) tem 5 CCTs:
- `000001` — Situações tributadas integralmente (regra geral, art. 4)
- `000002` — Exploração de via (art. 11)
- `000003` — Regime automotivo — projetos incentivados (art. 311)
- `000004` — Regime automotivo — projetos incentivados (art. 312)
- `000005` — Operação com EAC destinado à mistura com gasolina A (art. 179)

## Decisão

**Usar CST (3 dígitos) como chave primária para o campo `CST` na resposta da API. Armazenar CCT (6 dígitos) como coluna de metadado** na tabela `cst_reforma` para referência, auditoria e expansão futura.

```
cst_reforma
├── cst (CHAR 3)          ← retornado na API → TributoItem.CST
├── cct (CHAR 6) UNIQUE   ← metadado de auditoria
├── flags booleanas       ← lógica de negócio (monofásica, diferimento...)
└── url_legislacao        ← fundamento legal (artigo específico da LC 214/2025)
```

## Justificativa

- O CST (3 dígitos) é o código que vai no documento fiscal — é o contrato com o consumidor
- O CCT (6 dígitos) é relevante apenas para auditoria interna e fundamentação legal
- O mapeamento CCT→CST é N:1 (múltiplos CCTs para o mesmo CST)
- Se no futuro o documento fiscal passar a exigir CCT, a informação já está disponível na tabela

## Alternativas Consideradas

| Alternativa | Prós | Contras |
|-------------|------|---------|
| **A) CST na API, CCT como metadado** (escolhida) | Contrato simples, auditoria preservada | CCT não visível ao consumidor |
| B) CCT na API como chave primária | Máxima granularidade | Consumidor não precisa de CCT no documento fiscal atual, 164 valores é excessivo |
| C) Apenas CST, sem CCT | Mais simples | Perde rastreabilidade legal (qual artigo específico?) |

## Consequências

- **Positivas:** API simples (18 valores vs 164). Auditoria completa (CCT + URL da legislação). Preparado para evolução futura.
- **Negativas:** Se NF-e passar a exigir CCT, será necessário expor o campo na API (versão `/v2/`).
