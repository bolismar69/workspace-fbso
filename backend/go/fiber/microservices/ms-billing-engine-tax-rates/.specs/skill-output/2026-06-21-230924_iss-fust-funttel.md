### 3.1 Nova Arquitetura do Motor (Trifásico)

```
Fase 1 (Sequencial):        IPI
    └── Injeta ITEM_IPI_VALOR nos detalhes do input

Fase 2 (Paralela):          ICMS + PIS/COFINS + Reforma (CBS/IBS/IS) + ISS
    └── Injeta ITEM_ICMS_VALOR, ITEM_PIS_VALOR, ITEM_COFINS_VALOR nos detalhes

Fase 3 (Sequencial):        FUST → FUNTTEL
    └── Leem valores injetados para calcular base líquida
```

### 3.2 Padrão de Injeção Reversa (Fase 2 → Fase 3)

```go
// Após wg.Wait() da Fase 2, extrai tributos do response e injeta no input:
for i := range response.Itens {
    for _, trib := range response.Itens[i].Tributos {
        switch trib.Tributo {
        case "ICMS", "ICMS_PROPRIO", "ICMS_ST", "ICMS_DIFAL", "ICMS_SIMPLES":
            existing := models.GetDecimal(...)
            input.Itens[i].AddDetalhe("ITEM_ICMS_VALOR", existing.Add(trib.Valor))
        case "PIS":
            input.Itens[i].AddDetalhe("ITEM_PIS_VALOR", trib.Valor)
        case "COFINS":
            input.Itens[i].AddDetalhe("ITEM_COFINS_VALOR", trib.Valor)
        }
    }
}
```

Este padrão é o mesmo usado na Fase 1 (IPI → input) e permite que FUST/FUNTTEL leiam valores já calculados sem modificar a interface `domain.TaxCalculator`.

## 4. Regras de Negócio Implementadas

### 4.1 ISS (F-001)

| # | Regra | Implementação |
|---|-------|---------------|
| 1 | Identificar serviço via `ItemListaServico` (LC 116/2003 item 1.05 para telecom) | Detalhe `ITEM_LISTA_SERVICO` no item |
| 2 | Alíquota municipal `∈ [2%, 5%]` (BR-TAX-CONS-007) | Validação com `slog.Warn` se fora do range |
| 3 | `ISS = Preço_Serviço × Alíquota_Municipal` (BR-TAX-CALC-016) | `valorUnitario × quantidade × aliquota/100` |
| 4 | Retenção na fonte (tomador retém ISS) | Flag `ISS_RETIDO` nos detalhes do item |

### 4.2 FUST (F-002)

| # | Regra | Implementação |
|---|-------|---------------|
| 1 | Apenas SCM/STFC (não SVA) — BR-TAX-INF-007 | `TelecomClassifier.MustCalculateFUST()` |
| 2 | Base = `Valor_Serviço − ICMS − PIS − COFINS` (BR-TAX-CALC-019) | Leitura de `ITEM_ICMS_VALOR`, `ITEM_PIS_VALOR`, `ITEM_COFINS_VALOR` |
| 3 | Base negativa → FUST = 0 | `slog.Warn` + `baseLiquida = decimal.Zero` |
| 4 | `FUST = Base × 1%` (Lei 9.998/2000) | `baseLiquida × 0.01` |

### 4.3 FUNTTEL (F-003)

| # | Regra | Implementação |
|---|-------|---------------|
| 1 | Mesma base do FUST | Reutiliza `TelecomClassifier` + mesmas chaves de detalhes |
| 2 | `FUNTTEL = Base × 0,5%` (Lei 10.052/2000) | `baseLiquida × 0.005` |
