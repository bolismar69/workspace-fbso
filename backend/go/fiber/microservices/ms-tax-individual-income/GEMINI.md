# Contexto do Projeto

Você é o copiloto de terminal deste projeto. Todas as especificações funcionais e técnicas de negócio estão estruturadas e modularizadas no arquivo de mapeamento do repositório:
- .specs/INDEX.md

Siga rigorosamente a arquitetura Go/Fiber e as regras fiscais vigentes do domínio.

Voce deve sempre executar o planejamento das ações a serem executadas, quebrando as ações em partes menores para se executar a implementação de forma progressiva.
Voce deve apresentar o planejamento e aguardas as instruções para executar demais ações.
Voce só deve realizar implementaões e/ou desenvolvimento se tiver realmente recebido uma aprovação para executar.
